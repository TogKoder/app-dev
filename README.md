## Favorite Movies
1. Mad Max: Fury Road (2015)

2. Extraction (2020)
   - John wick but more brutal
3. John Wick (2014)
   - This movie changed how gunfight scenes should be choreographed
4. Project Hail Mary (2026)
   - The best movie in 2026 after so many movie flops in the same and the years prior
5. Saving Private Ryan (1998)
   - Changed how war movies should be portrayed and the incorporation of realistic elements, changed how soldiers depicted in films being shot to be realistic as possible and tactics were more realistic.
